# Updating This Site

This is a Jekyll-style GitHub Pages site. For local preview without Ruby, edit the source files below and run the Python renderer.

## Local Preview

After edits, run:

```bash
python3 build_site.py
```

Then open:

```bash
open _site/index.html
```

Or serve it locally:

```bash
python3 -m http.server 8000 --directory _site
```

Then visit `http://localhost:8000/`.

## What To Edit

| To update | Edit this file |
| --- | --- |
| Name, profile photo, pronunciation, bio, social links, CV link | `_data/about.yaml` |
| Research statement / research interests | `_data/about.yaml` |
| Publications / papers | `_data/research.yaml` |
| Publication card layout | `_libs/research_widget.html` |
| Publication section wrapper / filters | `_sections/research.html` |
| News / updates | `_data/updates.yaml` |
| Affiliations / institutions | `_data/affiliations.yaml` |
| Resources, GitHub repos, Hugging Face models/datasets | `_data/resources.yaml` |
| Resource card layout shell | `_libs/resources_widget.html` |
| Resource dynamic rendering | `js/scripts.js` |
| Footer links/text | `_data/footer.yaml` |
| Gallery content | `_data/gallery.yaml` |
| Overall page layout, metadata, CSS/JS includes | `_layouts/main.html` |
| Visual style, fonts, colors, spacing, cards | `styles/styles.css` |
| Affiliation carousel fixes | `styles/affiliations_fix.css` |

## Common Edits

### Add A Publication

Edit `_data/research.yaml` and add a new item under `projects:`.

Use this shape:

```yaml
  - title: Paper Title
    system-name:
    gif: assets/img/paper_fig/image.png
    conference: ICCV 2025
    conference-web:
    status:
    authors: <u>Md Ashiqur Rahman</u>, Coauthor Name, Raymond A. Yeh
    pdf: https://example.com/paper.pdf
    code: https://github.com/user/repo
    website:
    demo:
    slides:
    talk:
    poster:
    tutorial:
    abstract-less: Short first part of abstract.
    abstract-more: Remaining abstract text.
    tag: more_equivariance
    category: Equivariance
```

Put paper images in `assets/img/paper_fig/`. Keep your name wrapped in `<u>...</u>`; CSS turns that into the highlighted author style.

### Add A News Update

Edit `_data/updates.yaml` and add a new item near the top:

```yaml
  - picture: assets/img/updates_fig/example.png
    desc: New paper accepted at <highlight>Conference 2026</highlight>!
    time: Month 2026
```

`picture:` can be blank if no image is needed.

### Add A Resource

Edit `_data/resources.yaml`.

For GitHub:

```yaml
  - type: github
    git-api: https://api.github.com/repos/OWNER/REPO
    category: research
```

For Hugging Face:

```yaml
  - type: huggingface
    hf-type: dataset
    hf-id: ashiq24/DATASET_NAME
    category: research
```

Use `hf-type: model` for models.

For Hugging Face collections:

```yaml
  - type: huggingface
    hf-type: collection
    hf-id: https://huggingface.co/collections/ashiq24/COLLECTION_SLUG
    category: open-weights
```

For category filtering, `category:` must match a `data-filter:` value in the `categories:` list.

### Update Bio Or Research Interests

Edit `_data/about.yaml`.

Useful fields:

```yaml
first-paragraph: Your main bio text.
research-introduction: Your research statement sentence.
research-interests:
  - field: Computer Vision
    subfields: Geometric Deep Learning, Equivariant Neural Networks
```

### Update Images Or CV

Put files under `assets/`.

Common paths:

- Profile photo: `assets/img/profile_pic_3.jpeg`
- CV: `assets/doc/cv_ashiq.pdf`
- Paper figures: `assets/img/paper_fig/`
- Update images/logos: `assets/img/updates_fig/`

Then update the matching YAML path.

## Notes

- Edit source files, not `_site/`. The `_site/` folder is generated by `build_site.py`.
- `index.html` is also generated by `build_site.py` for static preview.
- GitHub Pages will build the real site from the Jekyll source after you push.
- If a local preview looks stale, run `python3 build_site.py` again and refresh the browser.
